
# 🧮 React Date Counter

A small, interactive React app that adjusts a date based on a counter and a step value. Perfect for practicing `useState`, component interaction, and working with JavaScript dates.

---
## 🚀 Features

- Increase/decrease **step** and **count** dynamically
- See the date update based on the counter
- Real-time calculation of days from or to today
- Clean and modern UI with responsive styling
